# Lunar globe textures

Source: [NASA Scientific Visualization Studio, CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/).
Credit: NASA's Scientific Visualization Studio, Ernie Wright (USRA), Noah Petro (NASA/GSFC), and the LRO LROC and LOLA instrument teams.

- `lroc_color_2k.jpg` supplies the orbital globe color from the global LROC mosaic and LOLA polar albedo.
- `ldem_3_8bit.jpg` supplies the orbital globe bump map from the global LOLA elevation preview.

Both files are used for rendering. The application's local terrain models still supply site elevations and slope.
